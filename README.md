# TalkTalk

같은 네트워크에 있는 사람끼리 **중앙 서버 없이** 대화하고 파일을 주고받는 데스크톱 메신저.
Windows / macOS. 만든 곳 [nion.kr](https://nion.kr).

대화는 서버를 거치지 않고 두 PC 사이에서 직접 오간다. 계정도 가입도 없다.

이 저장소는 **설치본만** 둔다. 받으려면 오른쪽 Releases 를 본다.
소스는 비공개다.

## 개발 일지

최신 순. 자세한 내용은 커밋 이력을 본다.

### 2026-08-21

- **읽음 표시** — 내 말풍선 옆에 아직 안 읽은 사람 수 (그룹은 남은 인원수)
- **날짜 구분선** (2026년 8월 21일 금요일)
- **답장** — 원문을 인용해서 보내기
- **오른쪽 단추 메뉴** — 답장·복사·저장·폴더·삭제 (삭제는 내 기록에서만)
- **Ctrl+V 로 사진 전송** (캡처 붙여넣기)
- **사진을 대화창에서 바로** 봄. 여러 장은 한 말풍선에 격자로 묶임
- **사진 창** — 썸네일을 누르면 열리고, 좌우로 넘겨 보며 확대·축소 (←/→, +/-, ESC)
- 대화 입력창을 카카오톡처럼 — **여러 줄 입력**(Enter 전송 / Shift+Enter 줄바꿈)과 아래 액션 줄
- 한글 조합 중 Enter 로 마지막 글자가 잘리던 문제 수정
- 1:1 대화에서도 말풍선 위에 보낸 사람 이름 표시, 연속 발언은 더 붙여서 표시
- 대화 목록에도 상대 프로필 사진 표시
- `npm run sandbox` 가 **패키징된 앱이 소스보다 오래되면 멈춘다** (옛 빌드로 시험하다 헤매지 않게)
- UI 아이콘을 **Material Design Icons** 로 교체 (이모지는 OS 마다 모양이 달라 줄이 흔들렸다)
- 버튼·입력칸·슬라이더를 **역할별 공통 컴포넌트**(확인/취소/보통…)로 분리하고, **버튼이 비활성처럼 보이던 문제**와 흐릿한 hover 를 고침
- 프로필 사진을 **원형**으로. 사진 자르기 미리보기도 원형
- 앱에 쓰는 색을 전부 밝게·어둡게 한 쌍의 토큰으로 정리 (CSS 에 색을 박으면 테스트가 잡는다)
- 프로필 사진과 이름을 지정하는 **프로필 편집 창** (친구 목록 맨 위의 내 프로필을 누르면 열림)
- 사진은 불러온 뒤 **끌어서 위치를 맞추고 휠로 크기를 조절해** 정사각형으로 자른다
- **그룹 대화 말풍선에 보낸 사람 아바타와 이름** 표시. 연속 발언은 한 번만 보여준다
- 친구 목록·대화 목록에도 상대 프로필 사진이 보인다 (한 번도 대화하지 않은 상대까지)
- 프로토콜 v3 — 프로필을 주고받는 `PROFILE` 메시지 추가
- **버전이 서로 달라도 대화는 되도록** 규칙을 바꿈. 앞으로 기능이 늘어도 한쪽만 업데이트한
  사람과 텍스트 대화·파일 전송은 계속 된다
- UI 레퍼런스를 카카오톡으로 통일
- `npm run sandbox -- 3` — 가상 Windows 안에서 인스턴스를 여러 개 띄워 테스트
- 다국어 지원 (시스템 / 한국어 / English). '시스템' 은 OS 가 한국어면 한국어, 아니면 영어
- 문자열을 `src/shared/messages/` 의 `ko.ts` · `en.ts` 로 모음. 번역을 빠뜨리면 컴파일 오류
- 언어를 바꾸면 이미 열려 있는 대화창과 트레이 메뉴까지 즉시 따라감
- 전송 실패 문구를 문장 대신 코드로 주고받게 바꿈 (언어를 바꿔도 옛 문구가 남지 않게)

### 2026-08-20

- 상대가 접속을 끊어도 대화 기록이 이름과 함께 남음 (`known_peers`)
- 그룹 방을 나가도 기록이 남고, 이름 없는 방은 참여자 이름으로 표시
- 프로토콜 v2 — X25519 핸드셰이크와 AES-256-GCM 암호화, 사칭 방지
- 그룹 대화 (메시 방식, 중계자 없음)
- 파일 전송 — 드래그 앤 드롭, 수락/거절, 진행률, 중단 시 부분 파일 정리
- 앱 테마 (시스템/밝게/어둡게)와 시그니처 컬러 적용
- UDP 브로드캐스트 스톰 수정 (초당 1,300개 → 3개)
- 하드웨어 가속을 꺼 상주 메모리 230MB → 153MB
- 방화벽에 수신이 막힌 상태를 화면에서 알려 줌
- 멀티윈도우 (본체 + 대화창 N개), 트레이 상주
- UDP 탐색 · TCP P2P · SQLite 저장의 기본 골격
