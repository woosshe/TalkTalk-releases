# TalkTalk

같은 네트워크에 있는 사람끼리 **중앙 서버 없이** 대화하고 파일을 주고받는 데스크톱 메신저입니다.
Windows / macOS. 만든 곳 [nion.kr](https://nion.kr).

대화는 서버를 거치지 않고 두 PC 사이에서 직접 오갑니다. 계정도 가입도 없습니다.
같은 공유기에 붙어 있으면 서로가 자동으로 목록에 나타납니다.

## 받기

오른쪽 **Releases** 에서 설치본을 받습니다. 서명하지 않은 설치본이라 Windows SmartScreen
경고가 뜹니다 — 「추가 정보」 > 「실행」.

## 0.2.1 — 2026-09-21

대화 순서가 뒤집히던 것과 화면이 따라 내려가지 않던 것을 고쳤고, 업데이트가 무엇을 하고 있는지
보여 드립니다.

### 추가

- **업데이트 진행률** — 설치본을 받는 동안 「다운로드 중… 36%」와 막대를 보여 드립니다. 예전에는
  누른 뒤 수십 초 동안 아무 안내가 없어 멈춘 것처럼 보였습니다
- **받기와 설치를 따로 누릅니다** — 다 받아도 바로 설치하지 않습니다. 받는 동안에도 앱을 그대로
  쓰시고, 설치할 때는 직접 고르시면 됩니다. 대화 중에 앱이 갑자기 닫히지 않습니다
- **새 버전이 나오면 알려 드립니다** — 예전에는 설정을 직접 열어야만 알 수 있었습니다. 이제 알림창이
  떠서 받을지 물어보고, 다 받으면 설치할지 다시 물어봅니다. 「나중에」를 고르시면 여섯 시간 동안
  조용합니다
- **같은 네트워크의 다른 분이 더 새 버전을 쓰고 계시면** 그때 스스로 새 버전을 확인합니다.
  대화에는 아무 영향이 없습니다

### 수정

- **대화 순서가 뒤집히던 것** — 두 컴퓨터의 시계가 조금만 어긋나도 나중에 쓴 말이 먼저 쓴 말 위로
  올라갔습니다. 이제 각자 자기 컴퓨터의 시계만 보므로 주고받은 순서 그대로 놓입니다. 시계를
  맞추실 필요가 없습니다. 이미 주고받으신 대화의 시각은 그대로 남습니다
- **새 글이 와도 맨 아래로 내려가지 않던 것** — 방금 보내신 말이 화면 밖에 남았습니다. 대화 목록에서
  들어온 모든 대화창에서 그랬습니다
- 설치본을 받다 실패하면 아무 말 없이 끝나던 것 — 이유를 보여 드립니다
- 받아 둔 설치본이 사라졌거나 망가졌으면 「설치」를 보여 드리지 않습니다
