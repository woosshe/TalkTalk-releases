# TalkTalk

같은 네트워크에 있는 사람끼리 **중앙 서버 없이** 대화하고 파일을 주고받는 데스크톱 메신저입니다.
Windows / macOS. 만든 곳 [nion.kr](https://nion.kr).

대화는 서버를 거치지 않고 두 PC 사이에서 직접 오갑니다. 계정도 가입도 없습니다.
같은 공유기에 붙어 있으면 서로가 자동으로 목록에 나타납니다.

## 0.2.0 — 2026-09-19

말풍선 하나에서 할 수 있는 일을 채웠습니다.

### 더한 것

- **이모지 반응** — 오른쪽 단추 메뉴 맨 위에 자주 쓰는 다섯. 한 사람은 한 말풍선에 하나만 달고,
  마우스를 올리면 누가 달았는지 칩 위에 뜹니다 (규격 5.9)
- **안 읽은 사람 보기** — 그룹에서 내 말풍선의 숫자를 누르면 아직 안 본 사람이 사진과 이름으로
  나옵니다. 방을 나간 사람에게는 「나감」이 붙습니다
- **부르기 @** — `@` 를 치면 그 방 사람이 뜨고 이어 치면 좁혀집니다. 나를 부르면 **그 방의 알림을 꺼
  뒀어도** 알립니다. 부른 자리는 세 갈래(내가 남을·남이 나를·남이 남을)로 다르게 보입니다
  (규격 5.10)
- **모두에게서 지우기** — 자기가 보낸 것만, 시간 제한 없이 거둬들입니다. 지운 자리에는 「삭제된
  메시지입니다.」가 남지만, **받는 쪽이 아직 안 읽었으면 통째로 사라집니다**
  (규격 5.11)
- **모아보기 창** — 모든 대화의 사진·파일·링크를 한자리에서 봅니다. 이름과 주소로 찾고, 「대화에서
  보기」로 그 말풍선 자리까지 갑니다. 대화별로 묶어서 보여줍니다
- **글꼴 고르기** — 목록만 있던 칸이 입력칸이 됐습니다. 「맑」만 쳐도 맑은 고딕이 남고, 목록의 각
  줄이 제 글꼴로 그려집니다
- **확대한 사진을 끌어서 훑어봅니다** — 스크롤바 대신 사진을 직접 끕니다
- **손 커서** — 끌어서 조작하는 자리에 손 모양을 직접 그립니다. **크기와 색을 Windows 설정에서
  읽어** 맞추므로 커서를 노란색으로 바꿔 쓰면 손도 노랗습니다
- **그룹은 참여자 얼굴로 보여줍니다** — 대화 목록의 그룹 아바타가 참여자 얼굴을 겹친 동그라미가
  됐습니다 (넷까지, 나는 뺍니다)
- **빈 화면 안내** — 아무것도 없을 때 그림과 함께 무엇을 하면 되는지 알려 줍니다. 처음 켠 사람이
  보는 화면도 「상대가 앱을 켜면 자동으로 목록에 나타납니다」로 고쳤습니다

### 고친 것

- 사진 한 장짜리 말풍선이 통째로 안 보이던 것 — 세로 상자에서 `flex-basis: 0` 이 폭이 아니라 높이를
  0 으로 만들었습니다
- 투명한 PNG 의 투명이 검게 차던 것 — 미리보기를 늘 JPEG 으로 구웠습니다. 이제 투명이 있을 때만 PNG
- 큰 사진의 말풍선 오른쪽이 80px 비던 것
- 창이 좁으면 사진이 잘리던 것 — 240 을 상한이 아니라 고정값처럼 썼습니다
- 오른쪽 단추 메뉴가 창 밖으로 나가 잘리던 것
- 말풍선 옆 빈자리에서도 오른쪽 단추 메뉴가 뜨던 것
- 글을 보내도 맨 아래까지 5px 이 남던 것
- 맨 아래 말풍선에 이모지를 달면 잘려 보이던 것
- 모아보기가 모든 글을 훑고 있던 것 — `LIKE` 패턴의 역슬래시가 템플릿 리터럴에 먹혔습니다
