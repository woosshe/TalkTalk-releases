# TalkTalk

같은 네트워크에 있는 사람끼리 **중앙 서버 없이** 대화하고 파일을 주고받는 데스크톱 메신저.
Windows / macOS. 만든 곳 [nion.kr](https://nion.kr).

대화는 서버를 거치지 않고 두 PC 사이에서 직접 오간다. 계정도 가입도 없다.

이 저장소는 **설치본만** 둔다. 받으려면 오른쪽 Releases 를 본다.
소스는 비공개다.

## 개발 일지

최신 순. 자세한 내용은 커밋 이력을 본다.

### 2026-08-21

- 다국어 지원 (시스템 / 한국어 / English). '시스템' 은 OS 가 한국어면 한국어, 아니면 영어
- 문자열을 `src/shared/messages/` 의 `ko.ts` · `en.ts` 로 모음. 번역을 빠뜨리면 컴파일 오류
- 언어를 바꾸면 이미 열려 있는 대화창과 트레이 메뉴까지 즉시 따라감
- 전송 실패 문구를 문장 대신 코드로 주고받게 바꿈 (언어를 바꿔도 옛 문구가 남지 않게)

### 2026-08-20

- 상대가 접속을 끊어도 대화 기록이 이름과 함께 남음 (`known_peers`)
- 그룹 방을 나가도 기록이 남고, 이름 없는 방은 참여자 이름으로 표시
- 프로토콜 v2 — X25519 핸드셰이크와 AES-256-GCM 암호화, 사칭 방지
- 그룹 대화 (메시 방식, 중계자 없음)
- 파일 전송 — 드래그 앤 드롭, 수락/거절, 진행률, 중단 시 부분 파일 정리
- 앱 테마 (시스템/밝게/어둡게)와 시그니처 컬러 적용
- UDP 브로드캐스트 스톰 수정 (초당 1,300개 → 3개)
- 하드웨어 가속을 꺼 상주 메모리 230MB → 153MB
- 방화벽에 수신이 막힌 상태를 화면에서 알려 줌
- 멀티윈도우 (본체 + 대화창 N개), 트레이 상주
- UDP 탐색 · TCP P2P · SQLite 저장의 기본 골격
