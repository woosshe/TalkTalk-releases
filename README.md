# TalkTalk

같은 네트워크에 있는 사람끼리 **중앙 서버 없이** 대화하고 파일을 주고받는 데스크톱 메신저입니다.
Windows / macOS. 만든 곳 [nion.kr](https://nion.kr).

대화는 서버를 거치지 않고 두 PC 사이에서 직접 오갑니다. 계정도 가입도 없습니다.
같은 공유기에 붙어 있으면 서로가 자동으로 목록에 나타납니다.

## 받기

오른쪽 **Releases** 에서 설치본을 받습니다. 서명하지 않은 설치본이라 Windows SmartScreen
경고가 뜹니다 — 「추가 정보」 > 「실행」.

## 0.2.3 — 2026-09-21

### 추가

- **새 메시지가 오면 그 대화창이 열립니다** — 트레이 아이콘만 바뀌어서는 자리를 비운 사이 온
  말을 놓치셨습니다. 이제 대화창이 뜨고 작업표시줄이 깜빡입니다.
  - **하던 일을 가로채지 않습니다** — 창은 뒤에 뜨고 포커스를 가져가지 않으므로, 다른 곳에
    입력하던 글자가 엉뚱한 창으로 들어가지 않습니다
  - 이미 열어 두신 창은 새로 띄우지 않고 작업표시줄만 깜빡입니다. 최소화해 두신 창도
    그대로 둡니다
  - **깜빡임은 메시지를 읽으시면 멈춥니다**
  - 알림을 끄셨거나 방해 금지 중이거나 그 대화의 알림을 꺼 두셨으면 **조용히** 트레이의
    숫자만 올라갑니다
  - 설정 › 알림 › 「새 메시지가 오면 대화창 열기」로 끄실 수 있습니다

지난 버전은 [변경 이력](CHANGELOG.md) 에 있습니다 ([English](CHANGELOG.en.md)).

이 저장소는 **설치본과 변경 이력만** 둡니다. 소스는 비공개입니다.
