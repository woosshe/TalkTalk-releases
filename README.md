# TalkTalk

같은 네트워크에 있는 사람끼리 **중앙 서버 없이** 대화하고 파일을 주고받는 데스크톱 메신저입니다.
Windows / macOS. 만든 곳 [nion.kr](https://nion.kr).

대화는 서버를 거치지 않고 두 PC 사이에서 직접 오갑니다. 계정도 가입도 없습니다.
같은 공유기에 붙어 있으면 서로가 자동으로 목록에 나타납니다.

## 받기

오른쪽 **Releases** 에서 설치본을 받습니다. 서명하지 않은 설치본이라 Windows SmartScreen
경고가 뜹니다 — 「추가 정보」 > 「실행」.

## 0.2.5 — 2026-09-28

엑셀에서 복사한 표를 표로 주고받습니다. 그룹 채팅에서 자리를 비웠던 분도 놓친 대화를 받습니다.

### 추가

- **엑셀에서 복사한 표를 표로 주고받습니다** — 셀을 복사해 붙여 넣으시면 보낼 표를 창으로
  먼저 보여 드리고, 「전송」을 누르시면 보냅니다
  - 받은 표는 말풍선에 그림처럼 줄여 보이고, 누르시면 원래 크기로 크게 보실 수 있습니다
  - 표를 고르고 복사하시면 엑셀에 그대로 붙습니다
  - **엑셀·이미지·PDF 로 저장**하실 수 있습니다. 아주 긴 표는 이미지 대신 PDF 를 권해 드립니다
  - 한글로 약 30만 자까지 한 번에 보내실 수 있습니다
- **그룹 채팅에서 자리를 비웠던 분도 놓친 대화를 받습니다** — 앱을 꺼 두셨던 동안의 대화가 다시
  켜시면 전해집니다(대화를 쓴 분의 앱이 켜져 있어야 합니다)
- **꺼져 있는 친구도 그룹 채팅에 넣으실 수 있습니다** — 친구가 앱을 켜면 초대와 그사이의 대화가
  함께 갑니다
- **친구를 두 번 누르시면 1:1 대화창이 열립니다** — 두 번 누르는 빠르기는 Windows 마우스 설정을
  따릅니다
- **친구 오른쪽 메뉴에 「프로필 보기」「1:1 대화」**를 넣었고, 폴더 이동은 「○○ 폴더로 이동」으로
  알아보기 쉽게 모았습니다
- **그룹 채팅 만들 상대를 고르실 때** 모든 친구 옆에 동그라미가 보이고, 고르지 않은 친구는 흐려집니다

### 수정

- **친구 목록의 「그룹」을 「폴더」로** 바꿨습니다 — 여러 명과 나누는 대화(그룹 채팅)와 이름이
  같아 헷갈리셨습니다
- **「폴더 없음」이 접히지 않던 것**
- **그룹 채팅 만들기 줄 아래로 뒤가 비쳐 보이던 것**
- **탭이 든 글을 고르면 말풍선 밖까지 칠해지던 것**
- **슬라이더 위의 손 모양 커서가 너무 크고, 창 가장자리에서 이동 모양과 번갈아 나오던 것** — 시스템
  손 커서와 같은 크기·테두리로 맞췄습니다
