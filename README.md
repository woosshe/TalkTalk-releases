# TalkTalk

같은 네트워크에 있는 사람끼리 **중앙 서버 없이** 대화하고 파일을 주고받는 데스크톱 메신저입니다.
Windows / macOS. 만든 곳 [nion.kr](https://nion.kr).

대화는 서버를 거치지 않고 두 PC 사이에서 직접 오갑니다. 계정도 가입도 없습니다.
같은 공유기에 붙어 있으면 서로가 자동으로 목록에 나타납니다.

## 받기

오른쪽 **Releases** 에서 설치본을 받습니다. 서명하지 않은 설치본이라 Windows SmartScreen
경고가 뜹니다 — 「추가 정보」 > 「실행」.

## 0.2.4 — 2026-09-28

못 보낸 말을 상대가 돌아오면 저절로 보내 드리고, 채팅 탭에서 모든 대화의 글을 찾으실 수 있습니다.
알림은 화면 구석에서 부드럽게 밀려 나옵니다.

### 추가

- **꺼져 있는 상대에게도 보내 두실 수 있습니다** — 상대가 꺼져 있으면 입력칸이 막혀 있었습니다.
  이제 글과 스티커를 보내 두시면 상대가 켜질 때 쓰신 차례대로 저절로 갑니다
  - 아직 가지 않은 말은 흐린 「전송 대기」로 보입니다. 누르시면 지금 다시 보냅니다
  - 파일은 두 분이 모두 켜져 있어야 오가므로 첨부는 계속 막혀 있습니다
- **채팅 탭 찾기가 모든 대화의 글까지 찾습니다** — 방 이름 아래 「메시지」 구획에 걸린 글이
  어느 방의 누구 말인지와 함께 나옵니다. 누르시면 그 대화의 그 말풍선으로 갑니다
- **업데이트를 마치면 알려 드립니다** — 조용히 시작을 켜 두셨어도 업데이트가 되었는지 알 수
  있습니다. 받아 두었던 설치본도 알아서 치웁니다
- **알림이 화면 끝에서 밀려 나오고, 사라질 때는 그리로 밀려 나갑니다** — 여러 개가 쌓이면 먼저 온
  알림이 위로 미끄러져 자리를 내어 줍니다. Windows 의 「애니메이션 효과」를 끄셨으면 움직이지
  않고 서서히 나타납니다
- **스티커 창이 저절로 닫힙니다** — 스티커를 보내시거나, 스티커 창과 그 대화창을 두고 다른 곳으로
  가시면 닫힙니다

### 수정

- **파일을 받을 때 알림·소리·작업표시줄 깜빡임이 없던 것** — 이제 새 메시지와 똑같이 알려 드립니다
- **알림이 여러 개일 때 사라지면서 남은 알림이 깜빡이던 것**
- **알림에서 마우스를 빼도 사라지지 않고 오래 남던 것**
- **알림이 화면 구석에서 멀리 떠 있던 것** — 구석에 더 붙여 띄웁니다
- **이모지 창에서 탭을 바꿀 때마다 같은 이모지가 쌓이던 것**
- **이모지 탭이 이모지처럼 보여 눌러도 안 찍히는 줄 아셨던 것** — 탭을 아이콘으로 바꾸고 목록과
  선으로 나눴습니다. 고른 탭은 아이콘이 채워집니다(본체 창·설정 창의 탭도 같습니다)
- **사내 서버를 고르고 주소를 비워 두면 업데이트 확인이 실패로 남던 것** — 주소를 적으실 때까지
  확인하지 않습니다
- 상대가 막 연결되던 중에 앱을 끄면 오류가 나던 것

지난 버전은 [변경 이력](CHANGELOG.md) 에 있습니다 ([English](CHANGELOG.en.md)).
