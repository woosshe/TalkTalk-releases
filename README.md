# TalkTalk

같은 네트워크에 있는 사람끼리 **중앙 서버 없이** 대화하고 파일을 주고받는 데스크톱 메신저.
Windows / macOS. 만든 곳 [nion.kr](https://nion.kr).

대화는 서버를 거치지 않고 두 PC 사이에서 직접 오간다. 계정도 가입도 없다.

이 저장소는 **설치본만** 둔다. 받으려면 오른쪽 Releases 를 본다.
소스는 비공개다.

## 개발 일지

최신 순. 자세한 내용은 커밋 이력을 본다.

### 2026-09-19

- **0.2.0 을 냈다** — 아래에 적은 것이 모두 들어 있다

- **글을 보내지 않고도 답할 수 있다** — 오른쪽 단추 메뉴 맨 위에 자주 쓰는 이모지 다섯이 한 줄로 놓인다. 판을 열 필요 없이 한 번에 달리고, 그 밖의 것은 「이모지 붙이기」로 들어간다. **한 사람은 한 말풍선에 하나만** 단다 — 하트를 달았다가 스마일을 달면 바뀌는 것이지 둘이 나란히 달리지 않는다. 같은 것을 단 사람들은 칩 하나로 묶이고, 마우스를 올리면 누가 달았는지 **칩 위에** 뜬다(OS 가 그리는 설명은 커서 아래에 떠서 정작 커서에 가린다)

- **그룹에서 누가 아직 안 읽었는지 본다** — 내 말풍선 옆 숫자를 누르면 사진과 이름으로 나열된다. 방을 나간 사람에게는 「나감」을 덧붙인다 — 기다려도 읽지 않는다는 뜻이다. 숫자와 목록이 어긋나면 「2명이 안 읽음」인데 한 명만 나오는 꼴이 되므로, 같은 자료를 같은 방식으로 센다

- **사람을 부른다** — 입력칸에 **@** 를 치면 그 방 사람이 뜨고 **@김** 처럼 이어 치면 좁혀진다. 위아래로 고르고 Enter 로 넣는다. 나를 부르면 **그 방의 알림을 꺼 뒀어도** 알린다. 부른 자리는 세 갈래로 다르게 보인다 — 내가 남을 부른 것, 남이 나를 부른 것, 남이 남을 부른 것. **나를 부른 자리만** 호박색이라 긴 대화에서도 바로 눈에 든다(강조색인 초록은 안 쓴다 — 내 말풍선이 같은 초록이라 받은 말풍선에 초록이 뜨면 그게 내 말인지 헷갈린다). 이름이 긴 사람부터 맞춘다 — 「김」과 「김정기」가 같이 있는 방에서 앞에서부터 맞추면 @김정기 가 @김 + 정기 로 쪼개진다([규격 5.10](docs/PROTOCOL.md))

- **보낸 글을 모두에게서 지운다** — 자기가 보낸 것만, 시간 제한 없이 거둬들인다. 지운 자리에는 「삭제된 메시지입니다.」가 남는다. **단, 받는 쪽이 아직 안 읽었으면 통째로 사라진다** — 메일 환수와 같다. 자리를 남기는 까닭은 「봤던 말이 사라져 헷갈리는 것」을 막으려는 건데, 못 본 말에는 그 문제가 없고 흔적만 궁금해진다([규격 5.11](docs/PROTOCOL.md))

- **모든 대화의 사진·파일·링크를 한자리에서 본다** — 본체 창 머리의 새 단추. 파일 이름과 주소를 같은 칸으로 찾고, 「대화에서 보기」를 누르면 **그 말풍선 자리까지** 간다. 링크는 웹 주소와 사내 공유 경로(`\서버\폴더`)를 모두 잡는다. 항목마다 대화 이름을 붙이는 대신 **대화별로 묶었다** — 훑기 쉽고 「그 방에서 오간 자료」라는 덩어리로 읽힌다

- **글꼴을 쳐서 고른다** — 목록만 있던 칸이 입력칸이 됐다. 「맑」만 쳐도 맑은 고딕이 남고, 공백과 대소문자를 무시하니 「맑은고딕」·「malgun」 어느 쪽으로 쳐도 찾는다. **목록의 각 줄은 제 글꼴로 그려진다.** 이 PC 에 깔린 글꼴이 백 개 가까워 훑어 내려갈 수가 없고, 이름만 봐서는 어떻게 생긴 글꼴인지도 알 수 없어서다

- **빈 화면에 그림과 안내를 붙였다** — 아무것도 없을 때 글만 두지 않는다. 그림 하나가 「여기는 원래 이런 자리다」를 먼저 말하고, 아래 한 줄이 무엇을 하면 되는지 알려 준다. 갈래마다 그림이 다르다. 처음 켠 사람이 보는 화면도 「같은 네트워크에 TalkTalk 사용자가 없습니다 · 상대가 앱을 켜면 자동으로 목록에 나타납니다」로 고쳤다 — 중앙 서버 없이 서로를 찾는 앱이라 이 점이 가장 설명이 필요하다

- **그룹은 참여자 얼굴로 보여준다** — 대화 목록에서 그룹 아바타가 참여자 얼굴을 **겹친 동그라미**가 됐다. 넷까지 쓰고 나는 뺀다 — 어느 방에나 내가 있어 얼굴 하나가 늘 같으면 구분에 보탬이 안 된다. 처음에는 2×2 격자로 잘라 넣었는데 40px 을 반으로 나누면 칸이 20px 이라 글자를 읽을 수 없었다. 겹친 동그라미는 22px 이 남는다. 겹침은 테두리 두께만큼만 준다 — 더 물리면 뒤 얼굴의 글자를 앞 동그라미가 먹는다

- **말풍선 옆 빈자리에서도 오른쪽 단추 메뉴가 뜨던 것** — 처리기가 말풍선이 아니라 **대화창 폭을 다 차지하는 줄**에 걸려 있었다. 이제 진짜 말풍선 위에서만 뜬다

- **맨 아래 말풍선에 이모지를 달면 잘려 보이던 것** — 자동 스크롤이 메시지 개수만 보고 있어서, 글이 늘지 않고 이모지만 붙으면 따라 내려가지 않았다. 스크롤을 올려 지나간 말풍선에 다는 것은 그대로 두고, **맨 아래를 보고 있을 때만** 따라간다

- **글을 보내도 맨 아래까지 5px 이 남던 것** — `scrollIntoView` 는 목록의 아래 여백(padding-bottom)까지 내려가지 않는다. 자리를 계산해 직접 내린다

- **창이 좁으면 사진이 잘리던 것** — 240 을 상한이 아니라 고정값처럼 쓰고 있었다. 고치고 나니 이번엔 **큰 사진의 말풍선 오른쪽이 80px 비었다** — 말풍선이 사진의 자연 크기로 먼저 굳고 그 뒤에 사진만 줄어서다. 말풍선에도 같은 상한을 줬다. 사진은 비율을 지켜 넣으므로 정사각형이면 240×240 이 되고 잘리지 않는다

- **오른쪽 단추 메뉴가 창 밖으로 나가 잘리던 것** — 폭을 180 으로 어림잡았는데 실제는 263 이었다. 이제 그려 놓고 재서 당긴다

- **모아보기가 모든 글을 훑고 있던 것** — 후보를 좁히는 `LIKE` 패턴의 역슬래시가 템플릿 리터럴에 먹혀 조건이 `'%%'` 가 됐다. 결과는 맞았지만 기록이 쌓일수록 느려질 자리였다

### 2026-09-18

- **확대한 사진을 끌어서 훑어본다** — 확대는 그림을 늘리는 방식이라 **스크롤바가 생기지 않는다**(8배로 키워 1600px 이 되어도 창의 스크롤 폭은 그대로였다). 그래서 그동안 확대하면 가장자리를 볼 길이 아예 없었다. 이제 사진을 잡고 끌면 따라오고, 밖으로 나간 만큼만 끌린다

- **끌어서 조작하는 자리에 손 모양 커서가 돌아왔다** — 슬라이더 손잡이와 사진 자르기 틀은 원래 손 모양이었는데, **Windows 에 그런 시스템 커서가 없어서** 앱이 직접 그린 그림이 커서 크기 설정을 무시하고 계단이 지는 문제로 다른 커서로 물러서 있었다. 이제 그림을 우리가 그린다 — 어떤 배율에서도 매끈하고, **커서 크기와 색을 Windows 설정에서 읽어다 맞춘다**(노란 커서를 쓰면 손도 노랗다). 색을 바꾸고 창으로 돌아오면 그때 따라간다

- **투명한 PNG 의 투명이 사라지던 것** — 미리보기를 늘 JPEG 으로 구웠는데 JPEG 에는 투명이 없다. 모서리를 둥글린 로고를 보내면 **검은 네 귀퉁이**가 생기고 반투명한 자리는 검정과 섞여 탁해졌다. 이제 투명한 자리가 있을 때만 PNG 로 굽는다. 규격은 그대로다 — 처음부터 PNG 를 허용하고 있었고 보내는 쪽만 굳어 있었다

- **말풍선에 이모지를 붙인다** — 오른쪽 단추 > 「이모지 붙이기」. 같은 이모지를 붙인 사람들이 칩 하나로 묶이고, 마우스를 올리면 **누가 붙였는지** 이름이 뜬다(그룹에서는 그게 곧 정보다). 한 사람이 여러 이모지를 붙여도 되고, 내가 붙인 칩을 한 번 더 누르면 떼어진다. 프로토콜은 그대로다 — 모르는 종류의 프레임은 옛 버전이 그냥 흘려보낸다([규격 5.9](docs/PROTOCOL.md))

- **사진 한 장을 보내면 말풍선이 통째로 안 보이던 것** — 시각과 「읽지 않음」 숫자만 남고 사진 자리가 0px 이었다. 사진은 멀쩡히 실려 있었는데(실측 480px) **칸이 높이를 못 가져서** 잘려 나갔다. 여러 장일 때 한 줄 안에서 폭을 나눠 갖게 하려고 칸에 걸어 둔 `flex: 1 1 0` 이, 한 장일 때는 칸이 세로 방향 상자의 직접 자식이 되면서 **폭이 아니라 높이를 0 으로** 만든 것이다. 부모의 높이가 내용에 따라 정해지니 나눠 줄 자리도 없었다. 비율 격자를 넣은 날부터 있던 것이다

- **0.1.5 를 냈다** — 아래에 적은 오늘 바뀐 것이 모두 들어 있다

- **처음 만나는 상대가 진짜인지 확인할 수 있다** — 1:1 대화창 메뉴의 「안전 번호 확인」. 두 사람의 화면에 같은 숫자(다섯 자리씩 여덟 묶음)가 뜨면 가운데에 끼어든 사람이 없다는 뜻이다. **프로토콜은 그대로다** — 사용자 번호가 이미 공개키의 지문이라 키를 따로 주고받지 않고 양쪽이 각자 계산한다

- **같은 이름을 쓰는 다른 상대가 있으면 대화창이 알려 준다** — 상대가 PC 를 바꾸거나 앱을 다시 깔면 키가 새로 생겨 사용자 번호가 달라지고, 화면에는 「같은 이름의 다른 사람」으로 보인다. 앱은 그것이 재설치인지 사칭인지 **가려낼 수 없지만 그런 상황이라는 것은 알려 줄 수 있고**, 가려내는 일은 안전 번호가 한다. 맞춰 본 뒤 「확인했습니다」를 누르면 그 줄이 사라진다. **키가 또 바뀌면 확인 표시도 저절로 풀린다**

- **갈라진 대화 기록을 이어 붙인다** — PC 를 바꾸면 같은 사람과의 대화가 둘로 갈린다. 「예전 대화 가져오기」로 옮겨 붙이되, **안전 번호로 확인해 둔 상대에게만** 길이 열린다. 되돌릴 수 없는 일이라 아무 대화나 붙이면 남의 기록이 엉뚱한 사람 것이 된다

- **친구를 목록에서 지운다** — 꺼져 있는 친구를 우클릭. **지우는 것이 아니라 잊는 것이라** 상대가 앱을 다시 켜면 저절로 돌아온다(그래서 「숨김 해제」 같은 화면이 없다). 이름은 남겨 두어 그 사람과의 옛 대화 제목이 그대로다

- **트레이 우클릭 메뉴를 채웠다** — 「열기 / 방해금지 / 종료」 셋뿐이던 것에 이름·버전, 안 읽은 대화로 바로 가기, 내 상태 다섯 가지, 대화 기록 관리, 설정, 윈도우 시작 시 자동 실행을 더했다

- **알림 팝업 그림자가 사방으로 조금씩 잘리던 것** — 카드 둘레에 남겨 둔 자리가 모자랐다. 번짐의 폭은 흐림 반지름의 절반이 아니라 **반지름 그대로**다(절반은 가우시안의 표준편차다). 보이는 카드의 크기와 자리는 그대로 두고 창만 넓혔다

- **업데이트를 사내에 올려 두는 법을 문서로 적었다** — 설정 창에 「사내 서버」와 「공유 폴더」를 고르는 자리는 있었는데, 거기 둘 `latest.json` 이 어떻게 생겼는지는 **어디에도 없었다**. [문서](docs/UPDATE-SERVER.md)에 규격·올리는 순서·안 될 때 볼 곳을 적고, `npm run manifest` 로 빌드 결과에서 `latest.json` 을 sha256 까지 채워 만들도록 했다 — 손으로 적을 때 제일 틀리기 쉬운 값이라서

### 2026-09-17

- **0.1.4 를 냈다** — 0.1.1~0.1.3 은 내렸다. 받을 수 있는 설치본은 0.1.4 하나뿐이다

- **설치 중에 뜨는 한국어 안내를 고쳤다** — 앱이 켜져 있는 채로 설치하면 "OK를 클릭하면 종료됩니다" 라고 물었는데, 정작 단추는 **[확인]/[취소]** 였다. 화면에 없는 단추 이름을 가리키고 있었고 취소하면 어떻게 되는지도 말해 주지 않았다. electron-builder 가 들고 있는 번역이라 `build/installer.nsh` 에서 덮어썼다. 번역이 아예 없어 영어로 나오던 네 가지(끄는 중·못 껐을 때·압축 풀기 실패·이전 파일 삭제 실패)도 함께 채웠다

- **모니터마다 배율이 다르면 프로필 편집 창만 확대돼 보였다** — 그 창만 1.5배쯤 커지고 아래가 잘렸다. 창은 열릴 때 깜빡이지 않도록 **화면 밖에서 태어나** 제자리로 옮겨 오는데, 태어나는 자리는 늘 맨 왼쪽 모니터다. 도착지의 배율이 다르면 Windows 가 "크기를 이만큼으로 바꿔라" 하고 알려 주지만, **크기를 못 바꾸게 해 둔 창은 그 알림을 흘려버린다.** 창은 옛 배율의 픽셀 크기 그대로인데 내용만 새 배율로 그려져, 380px 짜리 창 안에 253px 짜리 화면이 1.5배로 늘어나 들어갔다. 크기가 고정인 창은 프로필 편집 하나뿐이라 그 창만 그랬다. 이제 자리를 잡은 **뒤에** 크기를 다시 걸고, 사람이 창을 다른 배율의 모니터로 끌어다 놓아도 되돌린다
